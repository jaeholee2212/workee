# 작성 규칙
- 한 문장에 행동 하나를 쓴다.
- 필요 조건을 행동 앞에 쓴다.
- 사실, 가설, 미확인을 구분한다.
- 같은 개념에는 같은 용어를 쓴다.
- 완료를 확인할 증거를 지정한다.
- 규칙의 원본은 한곳에 두고, 다른 문서에는 적용할 행동과 원본 링크를 남긴다.
- 참조에는 읽을 조건과 필요한 절을 지정한다.
- 정책은 판단 규칙, 모델은 기록 항목·의미, 워크플로는 배정·전환, 하위 스킬은 실무 방법을 맡는다.
- 공동 탐구의 행동을 바꾸면 [대화 상황 검증](../tests/skills/wk-work-conversations.md)으로 실제 응답과 다음 행동을 확인한다.
