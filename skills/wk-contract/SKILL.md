# 동작 계약
1. 장부 규약, 완료 조건, 선택한 방향을 읽는다.
2. 입력 조건과 관찰 가능한 결과를 적는다.
3. 입력과 결과 사이에서 유지할 관계를 적는다.
4. 내부 구현 방식은 계약과 분리한다.

## 경계
- 현재 계약을 깨뜨릴 수 있는 경계 하나를 고른다.
- 실패 결과와 그대로 유지할 것을 적는다.
- 결정되지 않은 동작은 임의로 구현하지 않는다.

## 호환성
- 기존 소비자가 요구받던 조건과 받던 결과를 확인한다.
- 새로 요구하는 것과 더 이상 제공하지 않는 것을 표시한다.
- 같은 이름으로 다른 약속을 숨기지 않는다.
