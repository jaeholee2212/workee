# 탐색 규약

논의·계획에서 판단을 바꿀 불확실성을 줄인다.
`wk-work`는 각 빌딩 블록의 결과를 통합하고 다음 탐색을 실행할 책임을 가진다.
개별 스킬을 직접 사용하면 그 실행자가 요청 범위 안에서 같은 책임을 가진다.
행동 범위와 질문 여부는 [자율 진행과 사용자 판단](../SKILL.md#자율-진행과-사용자-판단)을 따른다.

## 탐색 반복

1. [현재 이해](work-model.md#현재-이해)와 요청한 결과를 확인한다.
2. 현재 설명이 놓치는 사용 상황·반례·가정을 찾는다.
3. 결론을 바꿀 가능성과 잘못 판단할 비용이 큰 질문을 고른다.
4. 조사 전에 가능한 관찰 결과가 가설이나 후보에 미칠 영향을 적는다.
5. 필요한 빌딩 블록으로 자료 조사·관찰·작은 실험을 수행한다.
6. 얻은 근거로 문제·제약·후보·판단을 갱신한다.
7. 결정 준비와 요청한 결과의 완료 조건을 대조한다.
8. 근거가 부족하고 실행 가능한 조사가 있으면 다음 질문의 탐색을 이어 간다.

- 기존 근거로 완료 조건이 충족되면 유효한 결과를 재사용한다.
- 질문은 조사 결과나 선택에 영향을 주는 이유와 연결한다.
- 여러 조사가 같은 질문에 답하면 비용이 낮고 후보를 잘 구분하는 방법을 먼저 택한다.
- 작은 가역적 선택은 필요한 차이만 확인한다.
- 영향이 크거나 되돌리기 어려운 선택은 강한 반대안과 실패 상황까지 검토한다.
- 새 근거가 기존 설명과 맞지 않으면 문제 정의나 비교 기준을 다시 연다.
- 근거 없이 남은 의문은 사실·사용자 판단·접근 불가 중 무엇이 부족한지 구분한다.

각 회차는 `새 근거 → 바뀌거나 유지된 판단과 이유 → 다음 질문`을 남긴다.
같은 설명의 반복이나 에이전트 간 동의는 추가 근거로 세지 않는다.
같은 방법으로 정보가 늘지 않으면 자료·가정·관찰 상황을 바꾼다.
조사할 가치가 있는 다른 방법도 없으면 그 한계를 종료 판정에 반영한다.

## 결정 준비

방향이나 설계를 선택하기 전에 다음 근거를 확인한다.

- 문제와 목표가 실제 관찰이나 확인된 사용자 요구에 연결돼 있다.
- 중요한 제약의 근거와 아직 가정인 제약이 구분돼 있다.
- 유력 후보의 차이가 같은 사용 사례와 문제에서 나온 기준으로 설명된다.
- 후보를 제외한 이유와 선택한 후보의 약점이 드러난다.
- 선택을 뒤집을 중요한 미정이 조사됐거나 대응 가능한 위험으로 남아 있다.
- 남은 위험을 감수할 근거와 잘못된 선택을 알아차릴 신호가 있다.

후보가 하나만 남으면 다른 접근을 제외한 근거를 확인한다.
결정할 필요가 없는 사실 확인 요청은 답과 출처의 충분성으로 판정한다.
근거가 부족하면 부족한 항목을 다음 조사로 연결한다.
후보 수·반복 횟수·문서 길이를 충분성의 근거로 삼지 않는다.

## 탐색 종료

| 조건 | 행동 |
| --- | --- |
| 요청한 결과의 완료 조건과 필요한 결정 준비가 충족됐다. | 근거를 기록하고 승인된 다음 행동을 실행한다. |
| 사용자만 할 수 있는 판단이 남았다. | 해당 판단만 묻고 독립적인 조사는 계속한다. |
| 필요한 근거에 접근할 수 없고 대체 조사도 없다. | 미확인 내용·선택에 미치는 영향·재개에 필요한 자료를 남긴다. |
| 사용자가 정한 시간·비용 한도나 실제 실행 한도에 도달했다. | 현재 가능한 판단과 유보할 판단을 구분해 남긴다. |

접근 제한이나 한도 도달을 결정 준비 완료로 처리하지 않는다.
미완료로 끝날 때는 가장 가치 있는 다음 조사와 재개 조건을 남긴다.
요청 범위 안에서 실행 가능한 유의미한 조사가 남으면 다음 행동의 제안만으로 끝내지 않는다.
