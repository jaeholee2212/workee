# 논의

문제·범위·방향의 중요한 미정을 해결한다.

## 시작 조건

- 현재 요청과 관찰 근거를 확인한다.
- 기존 목표·범위·결정과 그 근거를 읽는다.

## 진행

현재 판단을 막는 질문에 맞는 빌딩 블록을 선택한다.

| 부족한 내용 | 빌딩 블록 |
| --- | --- |
| 누가 어떤 상황에서 무엇을 못 하는지 | [wk-describe](../../wk-describe/SKILL.md) |
| 현상의 원인이나 목표를 막는 장애물의 근거 | [wk-diagnose](../../wk-diagnose/SKILL.md) |
| 이번에 풀 문제·범위·제외·완료 조건 | [wk-delimit](../../wk-delimit/SKILL.md) |
| 선택을 바꿀 대안 간 차이 | [wk-compare](../../wk-compare/SKILL.md) |
| 방향 선택이나 기존 결정의 재검토 | [wk-decide](../../wk-decide/SKILL.md) |
| 문제 자체의 타당성에 대한 별도 검토 | [wk-review](../../wk-review/SKILL.md) |

진단이 필요하지 않은 요청에는 진단 실험을 만들지 않는다.

## 산출물

- 확인한 문제와 목표
- 범위·제외와 완료 조건
- 선택한 방향과 이유
- 남은 미정과 다음 질문·행동

## 전환·중단

| 조건 | 다음 행동 |
| --- | --- |
| 계획을 바꿀 중요한 미정이 해소됐다. | 계획으로 진행할 수 있다. |
| 중요한 미정이 남았다. | 해당 질문을 조사하거나 필요한 선택을 기다린다. |
