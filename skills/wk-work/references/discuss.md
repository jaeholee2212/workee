# 논의

문제에 대한 이해를 넓히고 방향을 선택할 근거를 만든다.

## 시작 조건

- 현재 요청과 관찰 근거를 확인한다.
- 기존 목표·범위·결정과 [현재 이해](work-model.md#현재-이해)를 읽는다.
- [탐색 규약](exploration.md)을 읽는다.

## 진행

1. 사용자 목표와 현재 방해 요소를 구분한다.
2. 문제 정의를 바꿀 수 있는 사용 상황·반례·제약의 가정을 확인한다.
3. [탐색 반복](exploration.md#탐색-반복)에 따라 다음 질문에 필요한 빌딩 블록을 실행한다.
4. 결과를 현재 이해에 통합한다.
5. 결정 준비가 충족될 때까지 필요한 조사를 이어 간다.

| 필요한 근거 | 빌딩 블록 |
| --- | --- |
| 누가 어떤 상황에서 무엇을 못 하는지와 현상의 범위 | [wk-describe](../../wk-describe/SKILL.md) |
| 현상을 설명하는 가설이나 목표를 막는 장애물 | [wk-diagnose](../../wk-diagnose/SKILL.md) |
| 이번에 풀 문제·범위·제외·완료 조건 | [wk-delimit](../../wk-delimit/SKILL.md) |
| 가능한 설계 축·대안과 선택을 바꿀 차이 | [wk-compare](../../wk-compare/SKILL.md) |
| 근거가 쌓인 방향 선택이나 기존 결정의 재검토 | [wk-decide](../../wk-decide/SKILL.md) |
| 문제 정의나 유력한 방향에 대한 별도 반박 검토 | [wk-review](../../wk-review/SKILL.md) |

진단 실험은 관찰이나 자료만으로 구분할 수 없는 중요한 가설에 사용한다.
검토에서 반례가 발견되면 영향받는 문제·가정·후보를 다시 조사한다.

## 산출물

- 관찰과 연결된 문제·목표·사용 상황
- 확인된 제약과 가정, 범위·제외와 완료 조건
- 비교한 방향과 제외한 이유, 선택한 방향과 감수할 비용
- 선택을 뒤집을 조건, 남은 미정과 다음 행동

현재 요약은 `work.md`에서 갱신한다.
독립적으로 보존할 근거와 결정은 [장부 규약](registry.md#산출물-저장)을 따른다.

## 전환·중단

| 조건 | 다음 행동 |
| --- | --- |
| 방향의 [결정 준비](exploration.md#결정-준비)가 충족됐다. | 계획이 요청 범위에 있으면 설계 구체화로 이어 간다. |
| 결론을 바꿀 미정을 더 조사할 수 있다. | 해당 조사를 실행한다. |
| 사용자 판단·근거 접근·실행 한도 때문에 진행할 수 없다. | [탐색 종료](exploration.md#탐색-종료)를 적용한다. |

논의만 요청받았으면 근거를 갖춘 결론을 응답한다.
