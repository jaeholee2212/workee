# 논의 조율

문제·범위·방향에 필요한 결과를 하위 스킬로 조합한다.
현재 이해와 기존 근거를 입력으로 사용한다.
[결과에 따른 반복](../policies/progression.md#결과에-따른-반복)으로 부족한 근거를 보완한다.

## 스킬 조합

현재 부족한 결과에 해당하는 행을 선택한다.
유효한 결과는 재사용한다.

| 필요한 결과 | 실행할 스킬과 요청 | 다음 선택에 사용할 반환값 |
| --- | --- | --- |
| 현상과 사용 상황 | [wk-describe](../../wk-describe/SKILL.md)에 관찰 정리를 요청한다. | 사실·보고·미확인 범위 |
| 원인이나 목표를 막는 장애물 | [wk-diagnose](../../wk-diagnose/SKILL.md)에 판별할 질문을 맡긴다. | 가설별 근거·남은 설명 |
| 문제·범위·완료 조건 | [wk-delimit](../../wk-delimit/SKILL.md)에 문제 한정을 맡긴다. | 문제 진술·제약·가정 |
| 방향의 대안과 차이 | [wk-compare](../../wk-compare/SKILL.md)에 방향 비교를 맡긴다. | 비교 근거·제외 이유·중요한 미정 |
| 방향의 준비 판정과 선택 | [wk-decide](../../wk-decide/SKILL.md)에 준비 평가와 권고·위임된 결정을 요청한다. | 준비 여부·결정 상태·부족한 근거 |
| 문제나 방향에 대한 별도 검토 | [wk-review](../../wk-review/SKILL.md)에 대상과 검토 질문을 전달한다. | 반례·보완 항목·검토 근거 |

사실 확인만 요청받았으면 요청한 답에 필요한 스킬만 조합한다.
스킬이 새로운 중요한 질문을 반환하면 해당 질문을 다룰 스킬을 다시 선택한다.
하위 스킬이 자기 결과를 완료했어도 방향의 준비 판정이 부족하면 탐색을 이어 간다.

## 공동 검토와 탐색

문제나 방향을 함께 정할 때는 초기 관찰·잠정 해석부터 [대화와 탐색의 반복](../policies/collaboration.md#대화와-탐색의-반복)을 적용한다.
사용자와 문제 해석·대안을 검토하며 생긴 질문에 맞춰 조사·비교·검토를 배정한다.
반환된 근거는 [질문 선택](../policies/collaboration.md#질문-선택)에 따라 다음 대화나 조사로 연결한다.
달라진 문제·비교 기준·방향은 [공동 검토 기록](../references/work-model.md#공동-검토와-실행-위임)에 반영한다.
기존 합의의 재사용·검토 범위·응답 대기는 [자율 진행과 사용자 판단](../policies/progression.md#자율-진행과-사용자-판단)을 따른다.

## 단계 완료와 전환

- 문제·범위·완료 조건에 필요한 결과가 유효한지 확인한다.
- 방향 선택이 필요한 요청이면 결정 스킬의 준비 판정과 결정 상태를 확인한다.
- 문제나 방향을 선택하는 요청이면 [탐구 완료](../policies/collaboration.md#탐구-완료)의 근거 또는 유효한 위임을 확인한다.
- 남은 미정이 요청한 결과를 막는지는 반환된 영향과 수용 근거로 확인한다.

| 반환된 결과 | 조율 행동 |
| --- | --- |
| 문제 설명과 관찰이 맞지 않는다. | 현상 정리나 진단을 다시 배정한다. |
| 비교·결정·검토에 중요한 근거가 부족하다. | 부족한 근거를 다룰 스킬을 실행한다. |
| 근거는 충분하지만 공동 검토나 방향의 합의가 남았다. | 현재 해석·대안·남은 이견을 사용자와 검토한다. |
| 논의 결과와 공동 검토의 조건을 충족했다. | 계획이 요청 범위에 있으면 [계획](plan.md)으로 이어 간다. |
| 진행 정책의 종료 조건에 해당한다. | [종료와 재개](../policies/progression.md#종료와-재개)를 적용한다. |

논의만 요청받았으면 근거를 갖춘 결과를 응답한다.
