# 진단
1. [장부 규약](../wk-work/references/registry.md)을 읽는다.
2. 현상과 관찰 근거를 읽는다.
3. 가능한 설명을 둘 이상 구분한다.
4. 각 설명을 반박할 관찰이 무엇인지 적는다.
5. 아직 원인이 확인되지 않았으면 미확인으로 남긴다.

## 작은 실험
- 확인할 가설 하나를 고른다.
- 지지 결과와 반박 결과를 먼저 적는다.
- 결과를 적을 칸과 중단 조건을 만든다.
- 제품 변경과 진단용 변경을 구분한다.

## 실험 종료
- 관찰과 해석을 다른 문장에 쓴다.
- 지지, 반박, 판단 불가 중 하나로 기록한다.
- 남은 질문 하나를 적고 다음 실험은 별도로 결정한다.

## 산출물
- 작업 ID가 있으면 [산출물 저장 규칙](../wk-work/references/registry.md#산출물-저장)에 따라 `diagnosis` 용도의 파일로 진단 결과를 남긴다.
