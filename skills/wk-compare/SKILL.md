# 대안 비교
1. 장부 규약과 현재 문제를 읽는다.
2. 바꾸지 않는 선택을 포함해 다른 접근을 적는다.
3. 각 접근이 무엇을 하는지 한 문장으로 설명한다.
4. 아직 선택하지 않는다. 비교할 질문을 남긴다.

## 비교표
- 현재 문제를 구분하는 기준만 행으로 둔다.
- 셀에는 차이와 근거를 적는다. 숫자 점수로 판단을 숨기지 않는다.
- 모르는 셀에는 ?와 확인할 질문을 적는다.

## 근거 확인
- 선택을 바꾸는 질문 하나부터 조사한다.
- 일차 자료나 직접 관찰을 우선한다.
- 근거의 위치와 버전을 적고 추론은 추론으로 표시한다.
