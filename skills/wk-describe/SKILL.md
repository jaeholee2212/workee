# 현상 기술

1. [장부 규약](../wk-work/references/registry.md)을 읽는다.
2. 지정된 `work.md`를 읽는다.
3. 누가 어떤 상황에서 무엇을 보았는지 적는다.
4. 직접 관찰과 전달받은 보고를 구분한다.
5. 원인을 추측하지 않는다.
6. 현재 현상 한 단락을 남긴다.

# 관찰 근거

- 버그는 기대 결과와 실제 결과를 같은 조건에서 비교한다.
- 기능 요청은 현재 할 수 없는 사용자 행동을 확인한다.
- 조건과 대상 버전을 기록한다. 실행하지 않았으면 미실행으로 쓴다.

## 관찰근거 파일 예시

```
요청 (예상): GET /hello HTTP/1.1
응답 (목표): 200 OK
body (목표): hello
상태: 아직 구현, 실행하지 않음
```
